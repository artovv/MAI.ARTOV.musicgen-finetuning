В репозитории представлен код к выпускной квалификационной работе магистра на тему "Генерация аудио по ограниченным обучающим данным"

---

## Структура проекта
основной код представлен в директории "notebooks"
### 1. `preprocessing.ipynb` — Подготовка данных
В данном ноутбуке содержится код для:
- загрузки пользовательских аудиофайлов;
- автоматической сегментации треков на 30-секундные чанки;
- удаления вокала с помощью `Demucs`;
- генерации описаний с использованием модели CLAP;
- сериализации данных в итоговый датасет и его загрузка на HuggingFace.

---

### 2. `training.ipynb` — Обучение модели
Содержит цикл обучения модели `facebook/musicgen-melody`.

- реализован алгоритм дообучения FourierFT
- производится вставка адаптеров FourierFT в линейные слои модели
- реализовано дообучение модели с помощью двух стратегий: на основе функции потерь Cross Entropy и с использованием ранжирующей функции потерь на основе CLAP;
- производится сохранение весов обученных моделей

---

### 3. `evaluation.ipynb` — Оценка качества генерации
Код для оценки качества модели по нескольким метрикам:
- **CLAP Similarity**: семантическая близость к оригинальному аудио;
- **CLAP Diversity**: разнообразие между сгенерированными аудио;
- визуализация результатов и сравнение с базовой моделью.
